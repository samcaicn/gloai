## 5. 本期已交付：公告 / 通知系统（详情）

### 5.1 公告系统 `src-tauri/src/commands/announcements.rs`（新增）
补齐前端 `announcement-system` 的 6 个契约命令，`AnnouncementProvider`（已挂在 `App.tsx:420`）启动后即可正常拉卡片：

- `get_pending_announcements(token?)`：+1 open_count → MCP 更新检查 → 过滤内置卡片 → 按 priority 降序返回。
- `mark_announcement_seen` / `dismiss_announcement` / `never_show_announcement`：写状态（seen / 本版本忽略 / 永久屏蔽）。
- `trigger_announcement(id)`：绕过过滤按 id 手动取卡（供开发预览 Ctrl+Shift+Alt+D）。
- `get_announcement_tips()`：返回所有 tip 卡片。

设计要点：
- **类型与前端 `types/index.ts` 完全镜像**（snake_case wire format，tagged union `{type:...}`）。
- **版本化状态**：`announcements_state.json`（app_data 根目录，原子写 + 文件级 tokio Mutex，参考 tenant.rs）。app 版本变化时清空 seen/dismissed（让 `version_first_open` 卡片在新版本重现），`never_show` 跨版本保留。
- **内置卡片**：`feature_welcome`（新版本欢迎）、`feature_shortcuts_v0_2_2`（第 3 次打开的快捷键提示），id 与前端 DEBUG_CARD_IDS 对齐。

### 5.2 MCP 客户端更新查询
`get_pending_announcements` 内部调用 `mcp_proxy::mcp_call_v2("client.check_update", {current_version, platform})`：
- 有更新 → 生成 `client_update_<version>` 卡片（priority 200，最高），含下载地址 / release notes。
- **best-effort**：网络 / 解析 / 无 token 失败都只记日志、返回无更新，绝不阻塞公告加载。
- token 由前端 `AnnouncementService` 从 localStorage `trae_device_token` 读取后透传。

### 5.3 任务完成展示 `src-tauri/src/commands/notification.rs`（新增）
`send_system_notification({title, body?})` 用 `tauri-plugin-notification` 发 OS 级桌面通知。前端 `useDialogCompletionNotify` 在「对话轮次完成 + 窗口失焦」时已调用此命令，后端补齐后即生效。lib.rs 已 `.plugin(tauri_plugin_notification::init())`。
