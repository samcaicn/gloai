## 环境坑：git push 到 github 被死代理挡住（重要，下次直接复用）
- `C:/Users/User/.gitconfig` 全局配了代理：`http.proxy`/`https.proxy` = `http://127.0.0.1:1082`，且 **`http.https://github.com.proxy` = `socks5://127.0.0.1:1081`**（github 专用）。
- 用户本机 Clash/VPN（1081/1082）关闭时，端口超时 → `git push` 报 `Failed to connect to github.com:443 over proxy 127.0.0.1`。
- 只清 `http.proxy`/`https.proxy` 没用，**必须连 `http.https://github.com.proxy` 一起清**，且清掉后 SSL CA 链丢失需加 `http.sslVerify=false`（直连时）。
- 一次性推送命令：
  `git -c http.proxy= -c https.proxy= -c http.https://github.com.proxy= -c http.sslVerify=false push https://x-access-token:$TOKEN@github.com/samcaicn/gloai.git main:open --force`
- 更省事的做法：先让用户把 Clash/VPN 打开，代理通了直接普通 `git push gloai main:open --force` 即可。
