## raphael-web2api 绕过匿名日限（egress-IP 轮换）
- **实测证明限制机制**：Raphael 匿名日限（~2 图/天）是**按出口 IP** 计，不是 session/cookie。两个 brand-new browser context（同代理出口 IP 127.0.0.1:1082）都返回 `ANON_DAILY_LIMIT(used:2)`；清空 cookie 无效 → 新鲜 context 绕过不成立。本沙箱直连出口被墙（仅走代理），无法本地验证第二 IP。
- **唯一有效绕过 = 出口 IP 轮换（代理池）**：每个不同出口 IP 各自带 2/天额度；N 个代理 ≈ N×2/天。
- **实现（server.py v0.2）**：`Worker` 池按代理键（proxy URL 或 "direct"）索引，懒启动一个 Chromium/代理；`acquire_worker` 轮询选未耗尽的 worker；`generate` 遇 `ANON_DAILY_LIMIT` 标记 `worker.exhausted=True` 并轮换到下一个，最多 `max_proxy_retries` 次；全部匿名耗尽则回退 `RAPHAEL_COOKIES` 登录态（账号额度）。配置 `proxies`(list)/`rotate_proxies`(bool)/`max_proxy_retries`(int)，env `RAPHAEL_PROXIES`（换行/逗号分隔，"direct"=直连）。
