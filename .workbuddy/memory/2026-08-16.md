## 实现 BrowserSkill 安装策略（bsk CLI 自动装 / 扩展只引导）
- 设计决策（用户给出表格）：bsk CLI + 守护进程 **能**自动装（缺失时 `ensure_installed` 跑官方一键脚本，装到 `~/.local/bin`，幂等）；浏览器扩展 **不能**自动装（Chrome/Edge 禁止桌面应用静默注入），只能检测 + 深链商店 + 引导用户点一下。
- 新增 `opc/layer4_tools/browser_skill_setup.py`：
  - `ensure_bsk_installed(auto_run)`：先探测（PATH + `~/.local/bin`，因安装脚本写给未来进程 PATH，当前进程需直查安装目录）→ 缺失且 auto_run 时跑官方脚本（Windows `powershell irm|iex install.ps1`；unix `sh -c curl|sh install.sh`），再复探；返回结构化报告（already_present / installed / needs_install / install_failed / install_timeout / installed_but_not_on_path + manual 回退）。
  - `detect_extension()`：探测 `bsk browsers`→`bsk status`，容错解析（浏览器列表非空=已连；extension_connected 布尔；"not detected" 字符串；不确定则按未装处理给引导）。绝不尝试自动装扩展。
  - `extension_guidance()`：返回 `deep_link_command="bsk install-extension"`（官方自动弹商店页）+ Chrome Web Store / Edge 加载项 / GitHub releases(zip 开发者模式) 三路 + 步骤。明确 `auto_installable=False`。
  - `readiness_report(auto_install)`：CLI 状态 +（可选）自动装 + 扩展探测；未就绪附带 guidance。新增 3 个工具 `browser_skill_ensure_installed / _extension_guidance / _readiness` + specs。
- `registry.py` 已聚合 setup 工具/specs；`browser_skill.py` 的 `is_available` 缺失消息指向 `browser_skill_ensure_installed` 与 `browser_skill_extension_guidance`。
- 测试 `tests/test_browser_skill_setup.py` 新增 22 项全过；与既有 21 项合计 43 项通过（mock subprocess / which / 临时目录，无需真实 bsk）。
- 注意：真实 `bsk status/browsers` 的 JSON 字段名未核实（0.1.x 快速变），detect_extension 用容错启发式，待真实二进制验证后微调。
