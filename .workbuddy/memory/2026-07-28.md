# 2026-07-28 工作日志

## 修复 openScene 标签：静态/缺失 → i18n + 动态更新

- **问题**：4 个 `openScene` 调用点标签不当：
  1. `MainNav.tsx:319` — `openScene('automation', '自动化')` 硬编码中文，非具体软件名
  2. `MainNav.tsx:329` — `openScene('pipelines', '流水线')` 硬编码中文，非具体流水线名
  3. `TupaiHomeScene.tsx:211` — `openScene('skills')` 缺少标签
  4. `SkillsNavSection.tsx:37` — `openScene('skills')` 缺少标签
- **根因**：
  - `openScene(id, label?)` 的 `label` 存入 `SceneTab.label`，但 MainNav 渲染 open-tabs 时用 `def.labelKey ? t(def.labelKey) : def.label`，**完全忽略 `tab.label`**。
  - 当 tab 已打开且 `label` 为 `undefined` 时，`openScene` 保留旧 `t.label`（陈旧标签不重置）。
- **修复**（5 文件）：
  - `MainNav.tsx`：
    - open-tabs 渲染改为 `tab.label || (def.labelKey ? t(def.labelKey) : def.label)` — 支持 `tab.label` 动态标签。
    - `handleOpenAutomation` / `handleOpenPipelines` 改用 `t('scenes.automation')` / `t('scenes.pipelines')`（i18n，非硬编码中文）。
  - `TupaiHomeScene.tsx`：`openScene('skills', t('scenes.skills'))`。
  - `SkillsNavSection.tsx`：`openScene('skills', t('scenes.skills'))`。
  - `AutomationScene.tsx`：import `updateSceneTabLabel`；`handleSoftwareClick` 调 `updateSceneTabLabel('automation', sw.name)`；`closeDetail` 调 `updateSceneTabLabel('automation', t('scenes.automation'))` 重置。
  - `PipelinesScene.tsx`：import `updateSceneTabLabel`；`handlePipelineClick` 调 `updateSceneTabLabel('pipelines', pipeline.name)`。
- **设计**：导航入口点传 i18n 页面标题；场景内选中具体项时 `updateSceneTabLabel` 更新为具体名称；关闭/取消选中时重置为 i18n 标题。TupaiSkillsScene 点击技能即执行或跳走，无需动态标签。
- **验证**：`tsc --noEmit` 零错误。
