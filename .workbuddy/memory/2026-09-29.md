## 微信无人值守收发 — 修 CI 红（run 1191 → 修复后重推）
- 现象：run 1191 `assembleDebug` 失败，`processDebugResources` AAPT 报错
  `attribute android:defaultFilterType not found` / `android:packageName not found`
  （文件 `res/xml/wx_notification_listener.xml`）。
- 根因：通知监听过滤器元数据里这两个属性是**无命名空间**属性（运行时
  `NotificationListenerFilter.getAttributeValue(null,...)` 读取），加了 `android:` 前缀导致
  AAPT 在 android R class 里找不到 → 链接失败。
- 修复：去掉 `android:` 前缀及多余 `xmlns:android`，改为 `defaultFilterType="disallowed"`
  与 `<package-filter packageName="com.tencent.mm" />`。commit `c492210`，push 到
  `gloai` remote 的 `jev-chat-jarvis` 分支触发新 CI。
- 经验：job 日志 302→blob 必须**不带 auth header** 重新抓取；CI 失败详情在自动开的 issue #16 里。
- 待 CI 变绿后：确认 release APK 签名（沿用 run 1190 的 keystore secret），更新本记忆。
