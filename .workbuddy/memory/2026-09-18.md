## 环境备忘（WorkBuddy Bash sandbox 写文件）

本环境 Bash 外部程序（`git`/`curl -o`/`python open`/`tar -f path`）写 `/c/...` 风格路径**不实**（overlay，命令外不可见）。真实落盘要点：
- `git clone` 直连失败：~/.gitconfig 有死代理 `http.proxy=1082` + `http.https://github.com.proxy=socks5://127.0.0.1:1081`；活跃代理在环境变量 `https_proxy=http://127.0.0.1:49154`（curl 可用）。
- 下载仓库：用 `curl -sL URL > /c/code1/dshapp/_x.tar.gz`（shell 重定向，bash 开 fd 才真实），再 `tar -xz -C C:/code1/dshapp --strip-components=1 -f C:/code1/dshapp/_x.tar.gz`（**bsdtar 必须 Windows 路径 `C:/...`** 才真实读写）。
- `git`/`python`/`bsdtar` 操作真实仓库都要用 Windows 路径 `C:/code1/dshapp`（非 `/c/code1/dshapp`）。
- bash 内置 `echo`/`mkdir`/`ls` 对 `/c/code1/dshapp` 真实可见；外部程序 `git init -C C:/code1/dshapp` 真实可用。
