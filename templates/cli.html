基础调用

示例

{{ diag.venv_python }} cli.py status {{ diag.venv_python }} cli.py history --source owner --limit 5 {{ diag.venv_python }} cli.py config get ENABLE_AUTO_MESSAGE {{ diag.venv_python }} cli.py listen add SamCai_ 老板 {{ diag.venv_python }} cli.py send --who 文件传输助手 --msg 你好

加 --text 可切换为人读格式（如 cli.py history --source owner --limit 3 --text）。 需微信的命令（send / whois）在微信未登录时返回错误 JSON 并退出码 1，不会崩溃。

命令参考（9 个）

命令需微信说明
version否打印版本号
status否运行/配置摘要（监听名单、白名单、风格样本、聊天统计）
history否读聊天记录；--source owner|bot|friend|group|all --limit N
style否风格画像；--analyze / --profile / --enable / --disable
config get/set否读写配置项（原子写回 config.py；密钥脱敏）
listen list/add/remove否管理监听名单 LISTEN_LIST
send是发微信消息；--who --msg [--type file|image --path F]
whois是解析名字/微信ID
serve是前台启动 bot（长驻）
