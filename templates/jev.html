判断项含义

            
                
true_intent对方真实意图：试探你是否在意 / 发泄情绪 / 要具体行动 / 想知道原因 / 轻松闲聊 / 已收尾

                
danger_level关系危险度 0-9，越高越接近吵架或关系受损

                
she_needs对方现在需要：道歉 / 行动 / 解释 / 在意他的证明 / 什么都不需要

                
best_action建议动作：先查记录 / 道歉 / 给承诺 / 解释 / 表达在意 / 少说 / 定安排

                
should_reply_now下一条是否需要实质内容（否 = 别硬凑）

                
literal_question是否为字面意思（否 = 话里有话）

                
tension_resolved紧张是否已化解
