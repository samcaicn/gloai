传输方式默认 stdio。纯本地工具（status / history / style / config_* / listen_*）无需微信即可调用； send_message / whois 需微信已登录，未登录时返回明确错误而非崩溃。

暴露的工具（10 个）

工具需微信说明
status否运行状态与配置摘要（版本/登录开关/白名单/监听名单/风格样本/聊天统计）
history否读取本地聊天记录（SQLite），source: all/owner/bot/friend/group
style否主人对话风格画像（本地统计），action: show/analyze/enable/disable
config_get否读取配置项；密钥类（KEY/SECRET/TOKEN/PASSWORD）自动脱敏
config_set否写入配置项，原子写回 config.py
listen_list否列出当前监听名单 LISTEN_LIST
listen_add否加入监听名单（原子写回，首次自动清占位项）
listen_remove否移出监听名单（原子写回）
send_message是发微信消息；who 可为显示名/wxid/群wxid@chatroom；type: text/file/image
whois是解析名字/微信ID，返回 username 与 display_name

安全默认：不主动向任何人发消息（AUTO_MESSAGE_USER_LIST 为空）。要让 bot 主动聊天，须先用 config_set / listen_add 显式加入白名单。
