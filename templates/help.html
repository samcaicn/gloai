① 简介

WeAuto（原 WeChatBot_WXAUTO_SE）是运行在 Windows 10/11 桌面端的智能微信聊天机器人，基于内置 wechatauto 引擎驱动微信 4.x（兼容 3.9），调用大模型生成拟人化回复。

  • 支持微信 4.x / 3.9（仅 Windows 桌面客户端），macOS / Linux 暂不支持。
  • Web 配置后台端口：5001（默认 http://127.0.0.1:5001）。
  • 支持以 CLI（命令行）和 MCP（标准协议）被 Codex / WorkBuddy 等 agent 工具驱动。
  • 许可证：GNU GPL-3.0。

② 快速开始

方式一：一键启动器（推荐）

  1. 登录电脑微信（支持 4.x），保持后台运行。
  2. 双击 Run.bat：自动检查环境 → 安装依赖 → 检查更新 → 启动 Web 后台。
  3. 浏览器打开 http://127.0.0.1:5001，填写 API Key / 模型，配置监听名单，点击 Start Bot。

方式二：源码运行

python -m pip install -r requirements.txt --only-binary=:all: .venv_bot\Scripts\python.exe config_editor.py

方式三：打包 EXE

从 Release 下载 WeAuto.exe 双击即可（资源自动释放到同目录）；weauto_mcp.exe 为 MCP 服务独立可执行文件。

④ 主动消息白名单

为防止机器人对陌生人主动发消息，主动消息仅向 AUTO_MESSAGE_USER_LIST 中的对象发送。空列表 = 不主动给任何人发消息。

  • 配置项为 AUTO_MESSAGE_USER_LIST，值为微信显示名 / wxid 列表，例如 ['SamCai_', '文件传输助手']。
  • 匹配为双向：显示名或 wxid 任一命中即可。
  • 在「快速上手」或「配置编辑器」中设置；也可经 CLI config set AUTO_MESSAGE_USER_LIST 或 MCP config_set 写入。
  • 总开关 ENABLE_AUTO_MESSAGE 控制主动消息功能是否启用。

⑤ 风格模仿（Style Lab）

基于本地聊天历史（weauto_chat.db）统计主人的说话习惯，生成风格画像并注入 AI 回复。仅学习 source='owner'（主人亲发）消息，自动排除机器人代发内容。

  • 统计维度：句长、句末标点、emoji、语气词、口头禅、字级 n-gram、中英混用等。
  • 样本不足（<10 条）会提示数据不足，需先积累聊天记录。
  • 在「风格模仿」页可重新分析、开关、手工微调画像、清空画像 / 记录。
  • CLI：cli.py style --analyze / --enable / --disable；MCP：style 工具。

⑥ CLI 命令行

用项目自带 Python 运行（含 openai / wechatauto 等依赖），默认输出 JSON，加 --text 转人读格式。需微信的命令在微信未登录时返回清晰错误，不崩溃。

命令说明需微信示例
version打印版本否cli.py version
status运行/配置摘要（白名单、监听、风格样本数等）否cli.py status
history读聊天记录（--source all|owner|bot|friend|group）否cli.py history --source owner --limit 20
style风格画像（--analyze/--enable/--disable/--profile）否cli.py style --analyze
config get|set读写配置项（密钥脱敏）否cli.py config get ENABLE_AUTO_MESSAGE
listen list|add|remove管理监听名单 LISTEN_LIST否cli.py listen add "SamCai_" "朋友"
send发消息（--type text|file|image，file/image 需 --path）是cli.py send --who 文件传输助手 --msg 你好
whois解析名字/wxid → username / display_name是cli.py whois --name SamCai_
serve前台启动 bot（长驻）是cli.py serve
# 经 agent 调用（示例） .venv_bot\Scripts\python.exe cli.py status .venv_bot\Scripts\python.exe cli.py config set AUTO_MESSAGE_USER_LIST "['SamCai_']" .venv_bot\Scripts\python.exe cli.py listen list

⑦ MCP 协议

MCP（Model Context Protocol）让 Codex / WorkBuddy 等 agent 以标准协议驱动本机器人。stdio 传输，启动时按需懒加载，不触发微信 GUI。

客户端配置（mcp.json）

{ "mcpServers": { "weauto": { "command": "C:/path/to/weauto_mcp.exe", "args": [], "env": {} } } } // 源码运行：command 改为 ".venv_bot/Scripts/python.exe"，args: ["weauto_mcp.py"]

⑧ 常见问题 / 排障

  • 机器人不回复？ 确认微信已登录、监听名单已含对方、Start Bot 已启动；用「报错一键检测」自查。
  • API Key 无效（401）？ 确认 Key 对应 BASE_URL（默认 vg.v1api.cc/v1），Key 需在该网关有效。
  • CLI/MCP 报缺依赖？ 用项目自带 .venv_bot/Scripts/python.exe 运行；MCP 需要 mcp[cli]（含 typer）。
  • 主动消息发不出去？ 检查 ENABLE_AUTO_MESSAGE 与 AUTO_MESSAGE_USER_LIST 白名单。
  • 换电脑 / 更新？ 双击 Run.bat 自动检查更新；或用 updater.py 下载 Release 中的 WeAuto.exe。
  • 密钥安全？ 源码 config.py 仅占位；真 Key 在运行时副本，已被 .gitignore 屏蔽，不会进入仓库。
