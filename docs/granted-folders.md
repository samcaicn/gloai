# 保存到用户授权的手机文件夹

在设置的「手机目录」页面选择「选择可读写的文件夹」，通过 Android 系统选择器授权。Mika 可以读取、创建和更新该文件夹及已有子文件夹内的 UTF-8 文本，包括 Markdown 学习笔记、清单和总结。每个文件最多 1 MiB。点击「取消授权」保留文件，只撤回 Mika 的访问权限。

原有的手机目录线索及导入授权仍只用于读取和导入，不会自动升级成写入权限。新入口不需要所有文件访问权限、root 或手机助手；不把手机目录挂载到脚本环境。工具属于现有文件能力，因此仍要求设备支持文件与计算环境。第一版仅向用户在界面发起的有人值守任务提供授权文件夹访问；远程通道、定时任务及子任务不会获得这项权限。

## 文件工具

- `list_folder_files`：省略路径列出系统持久授权的文件夹；传入返回的目录路径列出其直接子项。返回可写状态，一次最多列出 200 项，超出时明确标记。
- `read_file`：接受列表返回的 `/folders/…` 标识，按字节分页读取文本，同时返回整个文件的 SHA-256。
- `write_file`：可以新建、替换或追加文本。新建不传版本；已有文件必须传上次读取返回的 expectedSha256，版本不一致不写入。
- `share_file`：将工作区生成的文本文件保存到 folderPath 指定的位置；已有目标同样要求 expectedSha256。不填 folderPath 时保留原有下载目录和文件卡片行为。

`/folders/…` 只供文件工具使用，不是脚本可访问的 Linux 路径。先在工作区生成文本，再导出到授权目录。第一版不新增创建目录、删除文件或二进制文件读写能力；通过系统文件管理器创建子目录、整理文件。

## 实现与限制

授权来源是 Android 的持久 URI 权限，逐次验证；界面操作、写入和撤销在同一进程锁下串行执行。撤销会等待已开始的写入结束，之后的操作被拒绝。目录内查找最多检查 2000 项，重复文件名拒绝写入，不通过猜测路径选择目标。

更新前检查原文版本，写入后读回验证。Android 文档提供方没有通用的原子替换接口：写入失败会尝试恢复旧内容或删除本次新建的残件；恢复失败会明确报告文件可能已改变，不假报成功。哈希检查可以发现读取后发生的修改，但不能阻止其他应用在最后检查与写入之间同时编辑同一文件。

不增加后台轮询或模型请求。单次读取、输出和用于恢复的内容受 1 MiB 文件上限约束；目录扫描也有数量上限。远程文档提供方的访问耗时仍取决于其自身响应。

## 验证

本地覆盖工具路由、中文分页、版本参数、导出分支、路径检查、大小上限，以及远程/无人值守任务不可访问。已有工作区工具、目录授权、资源与提示词检查一并回归。

`GrantedFolderFilesDeviceTest` 使用真实系统选择器和专用 MikaFolderTest645 文件夹，验证授权持久化、新建 Markdown、读取与追加、旧版本及缺失版本拒绝、越界和超限拒绝、工作区文件导出、撤销后在同一个任务内拒绝访问。测试只操作专用文件夹；运行前应创建空文件夹，运行中在系统选择器中选择它，结束后由测试执行者清理测试文件。
