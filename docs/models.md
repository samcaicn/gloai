# 模型与登录

简体中文 | [English](models.en.md)

Mika 不带模型，用你自己选的模型服务商：填一把 API Key，或者用账号登录。主模型要支持工具调用。

## 添加模型

打开设置里的「模型」（第一次打开 App 时也会引导你）。内置了一批常见服务商的预设，清单见 [README](readme/README.zh-CN.md) 里「支持的模型服务商」；其他服务商选「自定义」，OpenAI 兼容、Anthropic、Gemini、OpenAI Responses 接口都能接。

1. 添加服务商：选一个预设，或选「自定义」填接口地址；填 API Key。Ollama、LM Studio 这类自己机器上跑的服务，地址预填了默认端口，改成那台机器的地址即可，Key 可不填。
2. 点「测试并保存」，连上第一家时会自动选一个主模型。这家不提供模型列表、列表里没有你要的、或列模型出错时，点「手动填写模型名」填上服务商文档里的模型 ID，再点「测试并保存」：只用这个模型试调用一次，通了才保存。选用途时每家下面也都能手填，手填的标「手填」。实在连不上、又想先存下时，也可以点「不测试，直接保存」：只存地址和 Key，不列模型、不试调用，存下的这家标「没测试过」，之后在服务商页可以「重新测试」，或先刷新列出模型。没测过的模型不会自动当主模型，在这家选主模型时先试调用；主模型没测试通过、任务又因模型出错失败时，提示会指向这家的「重新测试」。
3. 主模型要支持工具调用。可选：看图模型（看懂界面、看图找按钮）、轻量模型（便宜快的即可，处理判断结局、提取记忆等小事）、语音转文字（见下文）。

前三个用途分别是：**主模型**（办事，要支持工具调用）、**看图模型**（描述界面、看图定位；新装默认不用，可选「用主模型」）、**轻量模型**（判断结局、提取记忆、理解意图等小事，默认用主模型）。「测试并保存」具体怎么试、模型列表上的能力标签怎么来，见[贡献指南里的模型配置细节](../.github/CONTRIBUTING.zh-CN.md#模型配置细节)。

模型能不能看图：服务商的模型列表写了就照它，没写（不少中转、自建服务都不写）按预设初值，自定义服务商默认当它看不了。在服务商详情里点一个模型，面板下面有「能看图」开关，你说了算，列表写了的也能改。主模型能看图时，截图直接附给它看，不必另调一次看图模型；看图模型选的就是主模型（或选「用主模型」）也算你说了主模型能看图，换走了就恢复。

### OpenDesign Go

订阅 [OpenDesign Go](https://go.open-design.ai/)，按[API 接入说明](https://open-design.ai/help/cloud-api/)创建工作区 Key。在 Mika 添加 **OpenDesign Go** 预设，填写这把 Key，点「测试并保存」。预设使用 Chat Completions，地址为 `https://amr-link.open-design.ai/v1`；Mika 会读取这把 Key 可用的模型。手填模型名时使用目录里的准确 ID，主模型须支持工具调用。看图能力取决于具体模型，屏幕任务请配置合适的视觉模型。

## 查看任务费用

用 DeepSeek 官方 API 时，可以在 **设置 › 任务运行** 打开「显示任务费用」。新任务结束后，Token 数旁会显示人民币估算。Mika 按官方价目表和本轮已记录的模型用量计算，工作日可能的高峰时段会显示峰谷价区间。部分请求无法估算时，金额旁会标「部分」。实际扣费以 DeepSeek 账单为准。

## Jev 决策模型（可选）

在「设置 › 模型 › 决策模型 · Jev」单独配置，默认关闭，不改变主模型、看图模型或轻量模型的选择。

| 服务商 | 完整请求地址 | 默认模型 ID |
|---|---|---|
| TypeSafe | `https://api.typesafe.ai/v1/systemone` | `jev-1.14.0` |
| OpenRouter | `https://openrouter.ai/api/v1/systemone` | `typesafe/jev-1.14` |
| 自定义 | 填完整的 System One 兼容接口地址 | 按服务商填写 |

填入这家服务商的 API Key，打开开关并点「保存」，从下一次任务生效。切换服务商预设时重新填写对应的 Key。「测试连接」只发送固定的问候语做分类，不发送聊天或屏幕，不保存或开启配置；这次测试也可能计入服务商用量。自定义地址须使用 HTTPS，本机和局域网服务允许 HTTP；聊天接口 `/chat/completions` 不能直接用在这里。

开启后，Jev 用于聊天入口的意图判断（讨论、读取、执行），以及已开启经验回放时的历史路线选择。意图判断会发送本次请求和少量近期对话；路线选择会发送请求、候选路线模板及从原话提取的参数。API Key 与配置加密保存在手机上。主模型仍负责规划、文字生成和工具调用，Jev 不直接操作手机，也不替代确认关卡。

没有合适候选、参数无法唯一提取、概率不足、接口出错或超时，都会回到原有模型流程。Jev 明确选择不复用路线时，则跳过回放，由主模型继续规划。关闭并保存后，新任务不再调用 Jev；已开始的任务使用启动时的配置。用量页按模型名记录这些请求；运行记录中的 `jev_intent` / `jev_route` 标明采用了决策、跳过回放还是回退。此版本没有接入图片、Box 定位、逐步界面动作选择或记忆生成。

## 语音转文字

按住说话时用的第四个用途，在「设置 › 模型 › 语音转文字」里选。默认用手机自带的语音识别，边说边出字，不花钱。手机没有、或认不准时，可以选服务商的语音模型：说完再转成字，用你的额度；列表里只列名字像语音模型的，没列出来的可以在每家下面手动填模型名。选的时候会先试转一小段静音，通了才选上，不通当场说原因。手机自带的识别如果按住后一直没有反应，Mika 会提示你来这里选一个，不会自己换成要花钱的模型。

## 用账号登录（不用填 Key）

添加服务商最上面是「用账号登录 · 不用填 Key」一组，点一家先看说明，再去浏览器里登录，登录后回到 Mika，能看到账号、可用的模型，可以直接设为主模型。

- **ChatGPT**（Plus 或 Pro，用你的套餐额度）：点「使用 ChatGPT 继续」，在浏览器里登录。
- **xAI / Grok**（SuperGrok 或 X Premium+ 订阅）：浏览器里打开 xAI 的确认页，核对手机上显示的短码后同意。这项登录借用 xAI 官方命令行工具的公开登录入口，不是 xAI 专门给 Mika 开的，xAI 可能限制这种用法；有的订阅档位登录后仍不能调用（提示 403），那时改用 xAI 的 API Key。
- **OpenRouter**：OpenRouter 官方给第三方应用的授权。同意后 OpenRouter 给 Mika 一把属于你的 Key（名字是 Mika），用量从你的 OpenRouter 余额里扣；不想用了，在 OpenRouter 的 Keys 页面删掉它。

退出登录只清这台手机上的登录信息。

## 查看当前额度

打开 **设置 › 模型 › Token 用量**。顶部按已配置的服务商显示当前额度，下方可以按日期查看本机记录的历史 Token 用量。

DeepSeek、Kimi 和硅基流动显示账户余额。OpenRouter 显示当前 Key 剩余可支出金额，点该行可在 OpenRouter 查看账户余额。ChatGPT 等服务商可点「管理用量」打开官方页面。点「刷新」可以重新查询当前额度。

## 思考强度

用 ChatGPT 登录、xAI 登录或 Responses 接口的模型，可在各用途卡片下调整「思考强度」；OpenAI 兼容、Anthropic Messages、Gemini 接口的模型，服务商在模型列表里写明了这个模型的档位时也可以调。默认用服务商默认值；选「用主模型」时也跟随它的强度，明确选同一个模型则可分别设置。档位优先采用服务商报告的列表（Anthropic 的模型列表逐个写明支持哪些档位，只能按预算思考的模型没有档位）；没报告时只有 Responses 一类提供手动选项，实际支持情况以服务端为准，OpenAI 兼容、Anthropic、Gemini 不猜。更高强度通常更慢、消耗更多 token。

## 响应速度

打开「设置 → 模型 → 服务商」，点开 OpenAI（API Key）或 ChatGPT 服务商里的具体模型，在「用作」面板里选「响应速度」。默认沿用服务端设置，也可以选 Fast 或 Ultrafast。这个设置随服务商和模型保存，对使用该模型的各个用途生效。加速档位由 OpenAI 按模型、项目或订阅授权，可能增加 API 费用或套餐用量。服务端拒绝某个档位时，可以切回「默认」。

## 上下文窗口与压缩

在「设置 › 模型」的用途卡片下打开「上下文与压缩」。窗口留空时沿用所选模型的窗口，压缩触发点留空时自动计算；也可以分别填入 token 数。触发点按整份请求计，包含系统提示词、工具定义和消息。比如窗口填 1,000,000 时，自动触发点为 967,000，也可以手填 600,000 提前压缩。输入时只写数字。界面显示允许范围和实际生效值，压缩后会留出一段余量再触发。

设置按服务商和模型保存，使用同一模型的各用途共享，下次任务生效。「重置」后保存即可恢复自动。以后重新选择模型导致窗口变小时，实际触发点会限制在新窗口的允许范围内。窗口覆盖只影响本地预算，服务端仍有自己的上下文上限。

## 用自己电脑或局域网里跑的模型

添加服务商时选「自定义」，接口地址填 `http://` 开头的也行，比如 `http://192.168.1.10:11434/v1`（手机和那台电脑在同一个 Wi-Fi 下）。本机和局域网的地址不加提示；不加密又不在局域网里的地址会提醒一句：API Key 和对话内容可能被同一网络里的人看到，能用 `https://` 就用。

## 网络代理

不想开全局 VPN、又需要代理才能连上模型服务时，在「设置 › 网络代理」填一个地址：`http://主机:端口` 或 `socks5://主机:端口`（`socks5h` 也行，域名都交给代理解析），需要账号密码时写成 `http://用户:密码@主机:端口`。地址加密保存在手机上，界面上只显示协议、主机和端口。

- 走这个代理的：调模型（对话、语音转文字、连接测试）、列模型、查询服务商额度、用账号登录时换令牌、在 App 里下载更新、内置浏览器，以及「文件与计算环境」里的命令（那里允许联网时）。
- 始终直连的：这台手机和局域网里的地址（localhost、127.x、10.x、172.16–31.x、192.168.x、100.64–127.x、`.local`、`.lan` 结尾的名字、不带点的机器名），所以 Ollama、LM Studio 这类本地模型不受影响。
- 连不上代理、或代理拒了账号密码时，会直接说是代理的问题，不会说成 Key 或模型不对。
- `https://` 开头的代理（先和代理本身建加密连接）只有「文件与计算环境」里的命令用得上，Mika 自己的连接照旧直连；想全部走代理请用 `http://` 或 `socks5://`。
- 内置浏览器要手机的 WebView 支持单独设代理才会走它；带账号密码的 SOCKS 代理浏览器用不了。这两种情况设置页那一行会写明浏览器直连。

## ChatGPT 换账号后提示工作区无权访问

如果浏览器提示“此应用仅对其工作区成员可用”，诊断代码为 `3p_login_workspace_scope_denied`，先确认选的是原先授权的 ChatGPT 账号及工作区。这个错误表示当前登录不符合该应用注册的工作区范围；不要仅凭它判断密码错误或套餐额度耗尽。

Mika 的 ChatGPT“退出登录”会保留注册的 `client_id`，供同一个账号再次登录。若你确实要换到另一个账号／工作区，反复退出再登录可能仍沿用旧绑定。可以重新建立连接：

1. 回到 Mika，取消仍在等待的登录。
2. 记下当前主模型、看图模型和轻量模型的选择。
3. 打开“设置 › 模型 › ChatGPT”，点底部的“删除这个服务商”并确认。它会删除该服务商的本机凭据、模型配置及注册 ID，正在使用它的用途需要重新选择；聊天记录保留。无需卸载 Mika 或清除整个 App 的数据。
4. 重新添加 ChatGPT 服务商，点“使用 ChatGPT 继续”，在浏览器选择要用的账号及工作区，完成授权后回到 Mika。
5. 重新选择各用途的模型，再发一条简短请求验证。取得模型列表只能证明登录／列模型成功，不能代替实际调用测试。

这条路径用于更换账号／工作区，不是绕过工作区访问控制。若新建连接后仍被拒绝，请确认账号有该工作区的访问权限，或联系工作区管理员；反馈时提供错误代码和 Mika 版本，遮掉邮箱、授权码及令牌。
