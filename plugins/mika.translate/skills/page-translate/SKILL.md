# 页面翻译

插件 `mika.translate` 已经装好。工具 `plugin_mika_translate_translate`（在本任务里第一次调用时要用户点头一次）负责切段与翻译，
技能只负责「读页 → 翻 → 怎么摆给用户看」这一步。

## 一、先读页面

按顺序试，第一个成功的就停：

1. **用户选中了文字** → 只翻选中的那一段（步骤二直接传这一段，不要读整页）。
2. `web_read_page`（`maxChars` 设 `30000`）：读当前标签的整页正文。正文超过 30000 字时，用返回的 `nextOffset` 接着读。
3. `web_read_page` 不可用（返回 `background_read_unavailable` 或 `page_not_loaded`）→ 改用 `run_command` 拉 HTML 再取正文：
   ```
   curl -sL --max-time 30 "<页面网址>" | sed -e 's/<script[^>]*>.*<\/script>//g' -e 's/<[^>]*>/ /g' | tr -s ' \n' ' \n'
   ```
   需要登录态的页面这条路拿不到正文，直接告诉用户「这页要登录，我在对话里翻不了，请贴一段过来」。

不要用截图 + 看图的路线：又慢又不准。

## 二、翻译

先定目标语言——**用户说了就按他说的，没说就简体中文**：

- 「翻译这页」「翻成中文」→ `target: 简体中文`
- 「翻成繁体」「转成台湾用语」→ `target: 繁體中文`
- 「译成英文 / 日文 / 韩语 / 德语…」→ 用他说的那个词原样传，`target: English` / `日本語` / `한국어` / `德语` 都行
- 他一次要两种（「中文和英文各来一份」）→ 调两次，同一份正文，`target` 换掉

不要自己把语言名翻成英文再传；用户怎么说的就怎么传，脚本会自己归一化（简繁、日韩英都有别名，
其他语言原样交给模型认）。用户没提语言、也没配默认时才是简体中文。

调用 `plugin_mika_translate_translate`：

- `text`：页面正文，**整段原样传**（不用自己切，插件会按自然边界切段，一段一次接口调用）。
- `target`：按上面「先定目标语言」的规则填；用户没说才留空（脚本回落 `MIKA_TRANSLATE_TARGET`，再回落简体中文）。
- `source`：能判断就填（`English`、`日本語`），判断不了留空。
- `style`：一般留空；用户明确要「直译」填 `literal`，要「读起来顺」填 `polish`。

一次任务里只调一次（用户要两种语言时是两次）。**不要**把正文拆成很多次调用——切段和限流都在插件里做完了。

返回分两种：

- `mode: "translated"` → 直接用 `translation` 字段。
- `mode: "segments"` → 说明用户还没配翻译接口。这时**你自己翻**：把每段的译文按 `n` 拼回去，
  术语和专有名词前后一致，原文里的网址、代码、人名保持原样。翻完在回复末尾加一句：
  「这次是对话里的主模型翻的。想让页面正文不走对话、更快更省，按 `translate_setup` 的说明配三个环境变量就行。」

出错时看 `error`：

- `api_failed` → 把 `message` 里的 HTTP 状态码和服务端原话**原样**转告用户（多半是 Key 失效或模型名不对），
  然后问他要不要重配；不要反复重试同一个错误。
- `too_long` → 页面太长，改用 `web_read_page` 的 `offset` 分页，一次翻 2 万字左右，翻完接着读下一页。
- `empty_text` → 正文没读到，回步骤一。

## 三、怎么摆给用户看

用户要的是「看懂这页」，不是要一份报告。默认这样给：

1. 第一行先给**一句话结论**：这页在讲什么（从正文第一段和标题判断，不要编标题里没有的内容）。
2. 然后按原文的章节/段落给译文。**长页面（正文超过 3000 字）不要整篇贴**：给「开头 3~5 段完整译文 + 后面每个小节一句话概括」，
   末尾问一句「要我把哪一节完整翻出来？」
3. 短页面（3000 字以内）可以整篇贴，保留原文的小标题和列表。
4. 术语表/数据/日期：原文里的数字、网址、代码、商品型号**一个都不改**。

**不要**做的事：不要说「我无法访问网页」这类话（先按步骤一试）；不要贴出大段原文再贴译文（用户要的是中文）；
不要在译文里加你自己的评论；不要总结成「这篇文章讨论了……」这种套话——直接翻。

## 四、翻完可以顺手做

- 用户说「存下来方便以后看」→ 把译文写到 `write_file` 的工作区文件，回复里给文件名。
- 同一页反复翻 → 提醒他「这页刚翻过」，把上次的结果直接给。
- 用户问「怎么让它翻得更快/不走对话」→ 调 `plugin_mika_translate_translate_setup`，把里面的三个环境变量念给他。
- 用户问「能翻译哪些语言」「怎么改默认语言」→ 调 `plugin_mika_translate_translate_languages`，按里面的说法回答。
