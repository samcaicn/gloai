Run the same steps once on each matching list item, one item per iteration, so the loop is decided once instead of per item. item names how to recognize items on the current screen (role/text/resourceId); body is the ordered steps to run for ONE item. In body, use "@item" as targetText to act on the current item, and end with the step that returns to the list (usually back) when each body opens an item. When the visible items are done, reveal=scroll scrolls to find more until the list ends, reveal=none stops at the visible ones. on_error says whether a failed item stops the loop (stop, default) or is skipped so the loop carries on (skip). Returns one compact summary (done, failed, per-item ok) instead of per-item screenshots. Use do_each when the same action repeats over several items (open → act → back); use do_steps for a fixed few steps on one screen, phone_run for a fixed route across screens.
