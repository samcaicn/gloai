When the task is "do the same thing to every item in a list" — open each one and read it, claim each reward, reply to each message — call do_each once instead of tapping each item one turn at a time: it runs your steps on every matching item and returns one short summary, so N items cost one call, not N turns. item says how to recognize an item on the current screen (role/text/resourceId). body is the ordered steps for ONE item: write "@item" as targetText to mean "the current item", and end with back when the body opens a sub-page. It advances to the next item by itself and, with reveal=scroll (default), scrolls down to find items not yet visible until the list ends; reveal=none stops after the visible ones. on_error=skip keeps going past a failed item, stop (default) reports and stops. Example — open each item, read its page, go back: do_each(item={"role":"Button"}, body=[{"op":"tap","targetText":"@item"},{"op":"observe"},{"op":"back"}], reveal="scroll"). Use do_steps for a few fixed steps on one screen, phone_run for a fixed route across screens.
